# تطبيق إدارة محل هواتف وإكسسوارات

تطبيق أندرويد (Kotlin + Jetpack Compose + Room) يعمل بدون إنترنت، بواجهة عربية RTL.

## المميزات
- **الرئيسية:** مبيعات وأرباح اليوم والشهر، المصروفات، دخل الصيانة، الديون، قيمة المخزون، تنبيه المنتجات قليلة الكمية.
- **المخزون:** هواتف (مع IMEI) وإكسسوارات، باركود (إدخال أو مسح بالكاميرا)، سعر شراء/بيع، كمية، حد تنبيه، بحث وتصنيف.
- **البيع:** سلة، مسح باركود لإضافة المنتج، خصم، اسم العميل، دفع كامل أو جزئي (دين). يخصم من المخزون ويحسب الربح.
- **المبيعات:** سجل الفواتير، تسديد الديون، و**مشاركة/طباعة فاتورة PDF** (واتساب أو أي تطبيق).
- **المزيد:**
  - **الصيانة** (استلام / جاهز / تسليم)
  - **المصروفات**
  - **المشتريات والموردين:** فاتورة شراء تزيد المخزون وتحدّث سعر الشراء، ودين لكل مورد وتسديده.
  - **التقارير:** اليوم / ٧ أيام / الشهر / الكل (مبيعات، ربح، مصروفات، صافي الربح، الأكثر مبيعاً، ديون العملاء، مستحقات الموردين).
  - **الإعدادات:** اسم المحل ورقمه (يظهران على الفاتورة)، نسخ احتياطي واستعادة.

## التشغيل
1. ثبّت **Android Studio** (إصدار حديث).
2. `File > Open` واختر مجلد `PhoneShop`.
3. انتظر مزامنة Gradle (يحتاج إنترنت أول مرة).
4. شغّل على محاكي أو جوال، أو من `Build > Build APK(s)` للحصول على ملف APK.

## الحصول على ملف APK
**الطريقة ١ (بدون تثبيت شيء):** ارفع محتوى المجلد إلى مستودع GitHub جديد، ثم افتح تبويب **Actions**
واختر **Build APK** ثم **Run workflow**. بعد دقائق ينزل ملف `AwabMaasai.apk` من قسم **Artifacts**.

**الطريقة ٢:** من Android Studio اختر `Build > Build APK(s)`، والملف يظهر في `app/build/outputs/apk/debug/`.

لتثبيته على الجوال: انقل الملف وافتحه، وفعّل "التثبيت من مصادر غير معروفة" عند الطلب.

## ملاحظات
- مسح الباركود يستخدم ماسح Google المدمج، ويتطلب أن يكون على الجوال خدمات Google Play.
- النسخة الاحتياطية ملف قاعدة البيانات نفسه. احفظه خارج الجوال بانتظام.
- لتغيير العملة عدّل `CURRENCY` في `Common.kt`.
- الكود لم يُبنَ داخل بيئة التطوير التي كتبته فيها، فإن ظهر خطأ عند أول بناء أرسله وأصلحه.
